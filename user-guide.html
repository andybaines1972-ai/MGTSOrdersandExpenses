Who can do what?

Role What they can do
Requestor
  • Submit Purchase Requests, Expense Claims and Mileage Claims
  • View and delete their own submissions
  • Track status of their requests
Authoriser
  • Everything a Requestor can do
  • Level 1 approval: Approve or reject Pending requests (moves to Approved)
  • View all pending items on the dashboard action queue
Finance
  • Everything an Authoriser can do
  • Level 2 authorisation: Authorise or reject Approved requests (moves to Authorised)
  • Process POs on authorised requests (mark as Processed)
  • View all submissions across all users
  • Export data to CSV / XLSX
  • Delegate finance authorisation to another user (holiday cover)
Admin / Finance
  • Manage users — add, edit, activate/deactivate, delete
  • Bulk import users via CSV
  • Set up finance delegation for holiday cover
  • View change log and system debug tools

Raising a Mileage Claim

All Roles
🧠
Smart pre-fill from your last claim When you open a new mileage claim the system automatically looks up your previous claim and pre-fills the Month Start Mileage, Vehicle Registration, and Vehicle Type for you. A confirmation toast appears at the bottom of the screen. You can override any pre-filled value before submitting.
  1. 1
    Click the Mileage Claims tab, then + New Mileage Claim

    Your previous claim's end mileage, vehicle reg, and rate are pre-filled automatically.

  2. 2
    Fill in the claim month and check your vehicle details

    Enter the Month End Mileage — the system calculates total mileage for you.

  3. 3
    Add journey lines using the postcode distance calculator

    Each journey row has From Postcode and To Postcode fields. Type both postcodes and click 📍 Calc — the road distance in miles is calculated automatically and fills the miles field. The description is also pre-filled if you leave it blank.

    • Use full UK postcodes, e.g. CV1 2WT or B1 1BB
    • You can still type miles manually if you prefer
    • Click + Add Journey to add more rows
  4. 4
    Enter Business Miles and click Submit Claim

    The total claim amount calculates automatically at the HMRC approved rate.

Authoriser / Finance

    Review the request

    Click Review to open the full request and see all details, items, and any attached documents.

  2. 2
    Add optional notes

    Use the Manager Approval Notes field to add any comments — particularly useful if rejecting to explain the reason.

Finance: Processing POs

Finance Only

Once a request is Authorised (both manager and finance have signed off), Finance can raise the PO, place the order, and mark it as Processed.

🔴
Finance dashboard shows your processing queue The Awaiting PO Processing stat card turns red when there are authorised items ready for POs. Click it to jump straight to the filtered list.
  1. 1
    Click the red Awaiting PO Processing card on the Dashboard

    This takes you to the Purchase Requests tab filtered to Authorised status.

  2. 2
    Open the request and review the details

    Check the supplier, items, total, and any attached quotes. You can also see both the manager approval and finance authorisation notes.

  3. 3
    Fill in the Finance Processing fields

    Enter the PO Number, Invoice Number, NL Code, PL Account, Payment Method, and any Finance Notes.

  4. 4
    Click Save & Process

    The request moves to Processed status.

✏️
Need to update finance details after processing? Open any Processed request and click Update Details to edit the PO number, invoice number, NL code, or other finance fields without changing the status.

Exporting Data

Finance / Admin

You can export all request data to CSV for use in Excel, your accounts system, or OneDrive.

  1. 1
    Per-tab export

    On the Purchase Requests, Expense Claims, or Mileage Claims tab, click the orange ⬇ Export CSV button. The file downloads immediately with all records visible to you (including current filter).

  2. 2
    Export everything at once

    In the Admin tab, click Export All Data to download a combined CSV with Purchase Requests, Expense Claims and Mileage Claims in one file, with a Type column to distinguish them.

💡
Excel compatibility All exported files include a UTF-8 BOM so they open correctly in Microsoft Excel without garbled characters.

Bulk importing users from CSV

  1. 1
    Download the template

    Click ⬇ Download Template to get a blank CSV with the correct columns: Name, Email, Role.

  2. 2
    Fill in the template

    Open in Excel. Add one row per person. The Role column must be exactly one of: requestor, authoriser, or finance (lowercase).

ℹ️
Deactivating users Click Edit next to a user and uncheck Active. Inactive users are hidden from authoriser dropdowns but their historical records remain.
🗑️
Deleting a user Click the red Delete button next to a user to remove their hub access immediately. This removes their role entry only — their Supabase login account remains and their historical records are preserved. Use Deactivate (Edit → uncheck Active) instead if you just want to stop them accessing the hub without losing their profile.
✉️
Inviting users to set their password Click the ✉ Invite button next to a user to send them an invitation email. They click the link in the email to set their own password, then sign in at the hub URL.

Finance Delegation (Holiday Cover)

Finance / Admin

When Finance is on holiday or unavailable, they can delegate the finance authorisation (Level 2) to another user for a specific date range. The delegate can authorise Approved requests but cannot process POs, access admin, or perform other finance-only functions.

  1. 1
    Go to Admin → Delegation tab

    This tab is only visible to Finance users.

  2. 2
    Select the delegate user

    Choose any active non-finance user from the dropdown (e.g. a senior authoriser).

  3. 3
    Set the date range and reason

    Enter the From and To dates for the delegation period. Add an optional reason (e.g. "Annual leave").

  4. 4
    Click Set Delegation

    The delegation is active immediately if today falls within the date range. The delegate will see a green Finance Delegate badge in their nav bar when they next sign in.

👤
What the delegate sees
  • A green Finance Delegate badge next to their role in the nav bar
  • A toast notification on login confirming their delegation period
  • Approved items appear in their dashboard action queue
  • Authorise and Reject buttons appear on Approved requests
⚠️
Revoking a delegation early If Finance returns early, go to Admin → Delegation and click Revoke next to the active delegation. The delegate loses finance auth powers immediately.
ℹ️
Delegation limits
  • Delegates can only authorise — they cannot process POs, access user management, or export data
  • Delegations automatically expire at the end of the To date
  • Multiple delegations can be active at the same time (e.g. for team cover)
  • All delegations are logged in the Change Log for audit purposes

Tips & Common Questions

All Roles
Q: I submitted a request but made a mistake — can I edit it?
Delete the request (if still Pending) and re-submit. Once authorised, contact Finance directly to make changes.
Q: I can't see the authoriser I need in the dropdown.
Only active authorisers appear. Contact Finance to check the user is set up correctly and marked as Active.
Q: I've forgotten my password.
Contact Andy Baines — he can trigger a password reset email from Supabase.
Q: I submitted a request but the Finance team can't see it.
Requests go through two levels of approval. If yours is still Pending, your line manager needs to approve it first. Once they do, it moves to Approved and Finance can authorise it. Finance can only process POs once it reaches Authorised.
Q: What's the difference between Approved and Authorised?
Approved means your line manager has signed off (Level 1). Authorised means Finance has also signed off (Level 2) and the request is ready for PO processing.
Q: Finance is on holiday — who can authorise my request?
Finance can set up a delegate before they go (Admin → Delegation). The delegate gets temporary authorisation powers for a set date range. If no delegation is set up, the request will wait until Finance returns.
Q: Can I use this on my phone?
Yes — the hub is fully responsive. Open the same link in your phone browser and it will adapt to the smaller screen.
Q: My mileage start reading didn't pre-fill when I opened a new claim.
This happens if you haven't submitted a mileage claim before — there's no previous claim to read from. It will pre-fill from your second claim onwards.
Q: The postcode Calc button shows "Postcode not found".
Check that you've entered a valid full UK postcode (e.g. CV1 2WT, not just CV1). The calculator uses Royal Mail postcode data so partial postcodes won't work.
Q: The authoriser I need isn't in the dropdown.
Only active users with the Authoriser role appear. Ask Finance (Andrew Baines) to add or activate them via the Admin tab.
Q: Will large photo attachments use up all our storage?
No — the hub automatically compresses images before uploading. Photos from your phone (typically 5–10 MB) are resized and compressed to around 200–400 KB. PDFs, Word docs and spreadsheets are uploaded at their original size. You don't need to do anything — it happens automatically.
Q: I processed a purchase request but entered the wrong PO number.
Open the request in the Purchase Requests tab, click Update Details (visible to Finance on Processed records), correct the PO number, and save. The status stays Processed.
